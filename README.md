I mappen `nyttigeFunksjoner` finnes selvlagde funksjoner som er brukt til å løse oppgavene.

Mer informasjon om funksjonene kan vises i Octave med:

`help funksjonsnavn`

Det anbefales ikke å bruke disse funksjonene i stedet for Octaves innebygde funksjoner.
De er laget hovedsakelig for egen læring.
